From one command to a shipped feature

  1. 1

    Install & init

    One curl drops the binary; specnaut init scaffolds agents, slash-commands, and the backlog into your repo — shaped for your harness.

  2. 2

    Plan

    /task plan writes a short brief, then chains itself through implementation, review, merge and push. Expert agents settle the architecture, security and performance choices; it stops only for what only you can answer — then runs on autopilot.

  3. 3

    Review

    A dedicated review phase runs the code and security reviewers — and the accessibility, dependency and performance experts when the change calls for them — plus the quality gates — format, lint, typecheck, tests — before anything merges.

  4. 4

    Ship

    Merge on green, with the release skill and a GitHub-Project-backed backlog keeping the whole team in sync.
